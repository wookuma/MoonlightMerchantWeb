# 준비 도우미 바로 실행 v1

- 상품별 버튼으로 보관 재고 진열·부족 상품 매입·재료가 있는 물약 제작을 실행한다.
- 수량은 기존 `getPreparationPlan`에서 계산하고 실제 거래·제작·진열 함수로 가능 여부를 검증한다. 미리보기는 경제 상태와 저장을 바꾸지 않는다.
- 진열은 보관 수량 중 현재 수요에 부족한 양만 더한다. 매입은 진열과 보관 완제품을 제외한 부족 수량만 구매한다. 제작은 원재료 판매용 재고를 남기고 현재 가능한 부족분만 만든다.
- 제작 수량은 공유 재료를 쓰는 독립 선택지다. 한 작업을 실행하면 모든 안내·비용·가능 수량을 새 상태에서 다시 계산한다. 한 버튼으로 매입/제작과 진열을 함께 수행하지 않는다.
- 매입 버튼의 금액은 골드 지출이며 제작 버튼의 금액은 재료 원가다. 제작은 추가 골드를 소모하지 않는다.
- 상태 revision을 함께 전달해 중복 클릭·이전 화면의 작업을 거부한다. 준비 중에만 실행하며, 실패 시 경제 상태 전체를 유지한다.
- 저장 형식은 8 그대로이며 개점 등 기존 자동 저장 시점을 유지한다.
