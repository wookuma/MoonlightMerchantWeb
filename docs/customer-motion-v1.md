# 손님 전체 동작 v1

내장 image_gen으로 기존 캐릭터를 참고해 로웬·테오·미라·셀레네 동작 PNG를 생성했다. 프롬프트 전문은 `customer-motion-prompts-v1.json`에 보관한다.

게임 파일은 `public/assets/moonlight/rowen-motion-v1.png`, `theo-motion-v1.png`, `mira-motion-v1.png`, `selene-motion-v1.png`다. 기존 `luna-motion-v1.png`와 함께 사용한다. 원본 RGBA를 보존하고 Phaser에서 4열×2행으로 나눈다. 정수로 나누어떨어지지 않는 크기도 프레임 경계를 정수 좌표로 계산한다.

- 0~3: 걷기, 4: 대기, 5: 눈 깜박임, 6: 구매 성공, 7: 구매 실패.
- 루나는 기존 1→2→3→2 걷기 순서를 유지하며 나머지 손님은 0→1→2→3을 재생한다.
- 테오 원본은 왼쪽을 향하므로 다른 손님과 반대의 반전 기준을 사용한다.
- 모든 손님은 1500ms 입장 → 1800ms 상품 확인 → 350ms 반응+1150ms 걷기로 퇴장한다.
- 상품별 수요에 맞는 이미지와 동작을 `src/game/art.ts`의 `customerMotions`에서 선택한다.
- 모달을 열면 이동·판단·프레임이 함께 멈추고, 해제 시 중복 진행 없이 재개한다. 이전 방문 콜백은 무시한다.
- 애니메이션은 Phaser 화면 표현이며 경제 규칙·날짜·저장 버전은 바꾸지 않는다.
- 상점 주인은 계산대에 머무르며 이번 손님 이동 작업에 포함하지 않는다.
