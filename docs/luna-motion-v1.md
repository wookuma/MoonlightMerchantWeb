# 루나 동작 v1 · 매대 상품 등록

내장 image_gen으로 기존 루나를 참고해 동작 시트를 생성했다. 생성·보완 프롬프트 전문은 `luna-motion-prompts-v1.json`에 보관한다.

- `public/assets/moonlight/luna-motion-v1.png`: 1774×887 RGBA, 4열×2행. 원본은 보존하고 Phaser에서 경계를 정수 좌표로 나눈다.
- 위쪽 0~3: 걷기 포즈. 가방 방향이 다른 0번은 제외하고 1→2→3→2 순서로 재생한다.
- 아래쪽 4: 대기, 5: 눈 깜박임, 6: 구매 성공, 7: 구매 실패.
- 이 문서는 루나의 첫 적용 기록이다. 현재는 [손님 전체 동작](customer-motion-v1.md)을 적용해 나머지 손님도 걷기·대기·반응을 재생한다.
- 퇴장 시작 350ms는 반응, 다음 1150ms는 걷기로 기존 총 퇴장 시간 1500ms를 유지한다.
- 모달이 열리면 타이머·이동뿐 아니라 Sprite AnimationState도 멈추며 닫을 때 재개한다.

매대 위 네이티브 버튼은 Phaser 진열대와 같은 좌표를 사용한다. 클릭·터치·키보드로 해당 상품의 등록·진열 탭을 열며, 닫은 뒤 매대 버튼으로 초점을 돌린다. 매대의 선택 상품은 임시 UI 상태이며 저장하지 않는다. 영업 중 진열 변경 금지 등 경제 규칙은 기존대로 검증한다. 현재 매대는 상품별 고정 매대이며 서로 다른 상품을 다른 매대로 옮기는 배치 기능은 아니다.
