# 판매 피드백 v1

- 구매 성공 시 손님 위에 실제 결과의 `+금액G`를 표시한다. 퇴장 이동과 함께 살짝 떠오르며 흐려진다. 별도 거래·타이머·이동을 생성하지 않는다.
- 구매 실패는 품절·미진열·예산 부족·가격 부담·거래 실패를 실제 결과의 reason에 맞춰 말풍선으로 표시한다.
- 방문 단계·세션을 식별해 가격 변경, 메뉴 전환, 이전 콜백이 중복 표시나 거래를 만들지 않게 한다. 모달 중에는 금액 효과도 멈춘다.
- 매대는 보관 재고까지 0이면 품절, 보관 재고가 있으나 진열 0이면 미진열, 진열 1개는 마지막 수량으로 구분한다. 남은 수량은 기존 진열 상태를 사용한다.
- 오늘 매출은 `getDayStats`로 개점 이후 실제 매출만 표시하며 준비 중 직접 판매와 퀘스트 보상은 포함하지 않는다.
- 남은 손님은 현재 응대 중인 손님을 포함하며 퇴장 완료 시 감소한다. 준비 중에는 예상 손님, 마감 후에는 0명이다. 확장 단계별 5/7/9명을 사용한다.
- 이 표시는 저장하지 않으며 경제 규칙·저장 버전 8을 변경하지 않는다.
