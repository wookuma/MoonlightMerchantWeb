# 숲 탐색 v1

- 준비 중 하루 2회, 약초 또는 버섯을 선택해 1개 수집한다. 확률·실시간 타이머·별도 이동 맵은 없다.
- `day.explorationUsed`는 0~2. 개점·마감에 유지하고 다음 날·새 게임에서 0이 된다.
- 수집 재료는 보관으로 들어가며 골드·매입액·총원가는 변하지 않는다. 제작과 판매는 기존 원가 배분 규칙을 적용하므로 0G 원가도 정상이다.
- 저장 어댑터가 있으면 수집 후보의 전체 준비 상태를 먼저 저장한 뒤 재료와 횟수를 함께 반영한다. 저장 실패·다른 창 충돌·보호 상태에서는 둘 다 반영하지 않는다.
- 버전 8은 `exploration` 체크포인트와 횟수를 저장한다. 버전 1~7은 `legacyV7SaveData.ts` 및 기존 검증기로 먼저 검증한 뒤 횟수 0을 보충한다. 읽기만으로 저장을 덮어쓰지 않는다.
- 수집량을 포함해 비정상 재고를 거부하는 상한 검증을 유지한다. 현재 제작법은 재료 수량보다 완성품 수량이 많아지지 않는다는 조건을 사용한다.
- 상점 오른쪽 아래 숲 탐색 버튼, 영업 준비·제작 모달에서 진입하며 모달 일시정지는 기존과 동일하다.
